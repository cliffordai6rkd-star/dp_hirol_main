# 响应蒸馏独立诊断（2026-11-14）

本次只增加 `test/` 下的诊断代码和本说明。正式网络、训练配置、训练脚本和正在运行的训练任务均未修改。

## 固定实验对象

- 教师：`data/outputs/2026.11.12/20.05.59_876448_fdp_dis_board/teacher/checkpoints/optimizer_step=00180000-action_mse=0.00470914.ckpt`，EMA、eval、冻结。
- 学生：从正在训练的 `2026.11.14/13.25.56_response_weighted` run 复制出的固定 EMA 快照，step **12199**，当时 best validation loss **1.66992885**。后续训练进展不影响本次对照。
- 目标：教师最终 `context_norm`，即 DiT 前的 context；学生编码路径不执行教师融合 FFN。
- 数据：沿用正式训练缓存的原始 train/validation 划分；两个划分中，自由、预接触、接触各取 2 个样本，共 12 个样本。每个划分覆盖两个 episode；这是小样本诊断，不是完整验证集效果。
- 原始教师缓存与重新计算的 target：最大样本 MSE 为 `4.01e-7`。响应缓存的逐元素最大差约 `0.0525`、最大样本 MSE 约 `1.07e-5`，量级远小于约 1 的 token 基线误差。
- GPU 测试使用 BF16、microbatch 1，不启用 compile；全部拟合结果只写入独立诊断目录。

结果目录：`data/diagnostics/2026.11.14/response_distillation/`。

## 1. 主要误差包含很大的无力矩基线差异

以下是 **6 个 validation 样本，按阶段各 2 个取平均** 的 global token MSE：

| 对照 | 自由 | 预接触 | 接触 |
| --- | ---: | ---: | ---: |
| 原图 → 学生图像路径，与正常教师比较 | 0.935475 | 1.011117 | 1.023056 |
| 当前学生渲染，与正常教师比较 | 0.927548 | 0.899181 | 0.732751 |
| 教师零力矩 context，与正常教师比较 | 0 | 0.012786 | 0.033445 |
| 原图 → 冻结教师 FFN 对照，与正常教师比较 | 0.000240 | 0.013098 | 0.033608 |

单独比较零力矩 context：原图学生路径的 MSE 在预接触、接触阶段分别约为 **0.995581、1.012022**。相比之下，教师自身由力矩引起的变化仅为 **0.012786、0.033445**。两者是不同对照，不能直接相减当作严格误差贡献率；但差距表明当前监督远不止在拟合力矩影响。

同一图像补走冻结 FFN 后，与教师零力矩 context 的误差约 `1e-4`。这只是定位误差来源的反事实对照，**未将 FFN 加入学生网络**。

进一步只用 train 样本 token 对拟合一个离线仿射映射（256→256），拟合教师零力矩 context：train MSE `0.944632 → 0.063562`，validation MSE `0.981026 → 0.177021`。这说明较多差异可由特征坐标变换解释；尚不能据此证明新增适配层后的完整策略有效。

## 2. alpha=0 与当前最终特征目标存在约束冲突

当前渲染形式为：

```text
I' = clip(I + alpha_hat * mask_hat * tanh(residual), 0, 1)
```

当 alpha 严格为 0，`I'=I`，RGB 参数无法改变 token，相关梯度为 0；但教师在 alpha=0 时仍执行融合 FFN，其最终 context 不等于原始图像 context。

使用真实 alpha 和教师区域做像素优化：自由样本 100 步 loss 完全不变。当前预测 alpha 并非严格为 0，6 个验证样本中的两个自由样本平均约 `0.00677`，平均有效 alpha×mask 约 `0.00145`。这允许很小的修改，但不能解决“自由空间应完全保持原图”与最终特征匹配之间的逻辑冲突。

因此，下列三个要求在这批自由样本上无法同时精确满足：

1. 学生跳过教师 FFN，且采用当前冻结图像编码权重；
2. alpha=0 时完全不改图像；
3. 精确匹配教师 FFN 后的最终 context。

## 3. 图像路径能够下降，但门控会限制已观察到的可拟合程度

直接为每张图像优化独立像素变量，绕过 RGB 生成网络，只保留相同的冻结 DINO 和 token loss。以下各阶段取 **一个 validation 图像窗口**，从原图起优化 1000 步：

| global token MSE | 自由 | 预接触 | 接触 |
| --- | ---: | ---: | ---: |
| 原图 | 0.954188 | 1.042264 | 1.033497 |
| 固定预测 alpha×mask | 0.764426 | 0.203303 | 0.146201 |
| 全图允许修改、alpha=1 | 0.115059 | 0.099168 | 0.099616 |

全图优化会明显改变图像；不是可直接部署的学生结果。上述数字是固定初始化和优化预算下找到的解，**不是理论下界**。特别是不能从剩余约 0.1 的误差推断任何图像都无法逼近目标。

100 步门控对照也显示：预接触样本的 global MSE 为预测门控 `0.423522`、相同区域但 alpha=1 `0.341996`、教师区域与真实 alpha `0.364083`。两个预接触验证样本的预测 alpha 均值约 `0.21427`，真实标签均值约 `0.48`；条件预测的预接触校准值得复查，但这不是全部误差来源。

## 4. 当前 RGB 网络有学习能力，但本次微型拟合未接近精确匹配

复制同一学生快照，在内存中训练原样 RGB 网络，只反复拟合 3 个 train 样本（每阶段 1 个），条件网络保持冻结。1000 步平均训练 combined loss 从 **1.292009 降到 0.843758**。

训练后 eval 的 global token MSE：

| 划分（每阶段 1 个） | 自由 | 预接触 | 接触 |
| --- | ---: | ---: | ---: |
| 微型训练集 | 0.848450 | 0.447100 | 0.417233 |
| 原划分中的验证图像 | 0.947666 | 0.974307 | 0.958414 |

这说明梯度链路能够学习，但没有在本次预算内精确拟合 3 个样本，也没有带来稳定的跨图像改善。由于图像门控约束、目标基线差异和优化设置同时存在，不能把剩余误差单独归因为“网络容量不足”。仅反复训练 3 个样本，也不是完整数据训练泛化能力的评价。

## 5. 加权项存在有效梯度；直接替换成固定噪声行为损失也不足够

在 4 个非自由 validation 样本上，原图处 global loss 与 response loss 的**门控后输入像素梯度**余弦为 `0.851–0.944`，响应项梯度范数约为全局项的 `1.25–1.51` 倍。该处没有观察到响应项梯度消失或两项方向明显相反；这不等同于所有网络参数处、所有训练阶段的梯度结论。

教师响应存在一定空间集中：两个验证预接触/接触样本中，前 10% token 占 L2 响应权重约 **27% / 28%**。加权确实会改变监督分配，但加权的最终 token 误差仍然包含较大的无力矩基线差异。

另外在预接触、接触各一个 validation 图像上，用原有预测门控直接优化像素，比较同为 100 步的 token objective 与 DiT denoiser objective。后者只使用固定噪声和 4 个固定时间步作为拟合目标。

重新检查使用 **3 个新噪声 × 4 个新时间步（9、33、58、88）**；完整 8 步扩散使用 3 个匹配随机种子。以下是反归一化后、相对教师的完整动作序列 RMSE，按 3 个种子取平均：

| 像素拟合目标 | 预接触 | 接触 |
| --- | ---: | ---: |
| 当前已训练学生 | 0.038329 | 0.039833 |
| token loss，100 步 | 0.019709 | 0.014648 |
| 固定噪声 denoiser loss，100 步 | 0.028149 | 0.036146 |
| token loss，1000 步 | 0.011259 | 0.004314 |

固定探针行为优化确实降低了独立噪声上的 denoiser MSE，但同预算的完整动作一致性不如 token 优化；并非完全不泛化，也不能当作足以替代当前目标的证据。

所有像素拟合均使用了被评估图像本身的教师目标。新噪声测试只检查噪声维度上的迁移，不是图像泛化。动作一致性也不等于闭环任务成功率。

## 建议的先后顺序

1. **先处理零力矩基线坐标，再加强力矩蒸馏。** 在保留教师最终 context、学生不复用教师 FFN 的前提下，下一步值得测试的是轻量特征校准。离线仿射结果只提供候选证据，还需要更大 episode 划分和动作指标验证。若完全不允许校准层，则必须考虑允许自由空间进行基线图像变换，或调整监督目标及下游 DiT 的兼容方式。
2. **暂不把增大响应系数或扩大主干作为第一步。** 现有响应项有输入梯度，原结构也能下降；它们不能解除 alpha=0 时的约束冲突。
3. 基线对齐后，再决定是否加入真正的条件响应差：`Delta Z_S = Z_S(I,tau)-Z_S(I,0)`，对齐 `Delta Z_T = Z_T(I,tau)-Z_T(I,0)`，并保留最终 context/行为锚点。两边减各自的零条件分支，和两边减去同一个常量基线不同；但单独拟合增量仍不能保证 frozen DiT 所需的绝对 context 正确。
4. 复查完整验证集上的预接触 alpha 校准，避免力矩响应尚小且 alpha 又被低估时，RGB 修改空间过窄。不要根据这两个样本直接重设全局阈值。
5. 后续若加行为蒸馏，训练应覆盖随机噪声/时间步，并继续检查匹配种子的完整动作和独立 episode；不要仅按固定 denoiser 探针选方案。

以上为测试结论与下一步建议，尚未实施任何网络或训练改动。
