# CR-VTF 可视化实验：信息保留与力觉利用

目标是用同一个训练完成的 CR-VTF checkpoint，在独立验证 episode 上做推理诊断，不重新训练消融模型。需要分别回答：结构保留了什么、动作头是否使用了这些信息、力矩对图像融合的影响是否有益。后两点不能由特征图相似或 attention 较亮直接推出。

以下协议针对旧高分辨率 skip 和 800-token 输出。已完成旧教师第 75 轮的固定图像力矩干预，见 [小规模验证报告](../model_output/diagnostics/visual_torque_transfer_20261114_011928/report.md)。当前新默认为无 skip、无上采样的 196-token 视觉输出；下面的上采样不变量和输出力矩槽替换不适用于该新接口。

## 固定条件与特征命名

- 使用固定 checkpoint、固定验证窗口、`eval()` 和关闭梯度的推理；ACT 应有确定性重复输出。DiT 使用完全相同的初始采样噪声和采样步数。
- 所有实验复用同一批验证 episode，覆盖不同接触阶段及不同视觉细节，不按热图效果挑选成功样本。阶段标签仅用于分组，干预后不重新标记阶段。
- 每路相机、每个观察时刻分别捕获 `P`、`C`、`M`、`U(M-C)`、`P_out` 和更新后的力矩 token `T_out`。`P` 是 DINO patch 投影并加入嵌入后的高分辨率特征，`C=D(P)` 是池化特征，`M` 是联合 self-attention 的图像输出。
- `P_out=P+U(M-C)` 指最终 `context_norm` **之前**的图像特征。归一化之后的实际 ACT 输入需要另外记录，不能把前者的代数结论直接套给后者。

## 图 1：保留了哪些空间特征

每个相机绘制同一帧的 RGB、`P`、`U(M)`、`P_out`，辅以空间细节分量与差值图。特征 RGB/PCA 显示必须共享由参考 `P` 拟合的同一个中心和基底，所有条件使用相同色标；不要分别拟合 PCA 或逐图 min-max。

对实际的双线性上采样算子构造矩阵 `B`：将 49 个独立的 7×7 基向量按代码相同的 `bilinear, align_corners=False` 上采样到 14×14，得到 `B∈R^(196×49)`。用薄 QR/SVD 求其列空间正交基 `Q`，定义：

```
N = I - Q Qᵀ
P_out = P + B Δ
N P_out = N P
```

显示 `NP`、`NP_out` 以及 `NP_out-NP`，报告相对误差 `||NP_out-NP||F / (||NP||F+ε)`。对当前 7→14 算子，`B` 的秩为 49，因此每通道有 147 个不受粗尺度更新改变的空间方向。误差应接近所用数值精度的舍入误差。

这证明的是**相对于输入特征 P，粗尺度上采样无法表达的空间分量被 skip 保留**，不证明原始 RGB 全部信息无损，也不证明动作头用了它。不要用 `I-UD` 替代 `N` 宣称精确不变量：实际平均池化与双线性上采样不满足 `DU=I`。

在 `context_norm` 之后另外比较 patch 余弦相似度、局部特征距离矩阵，并将差异放回图像网格。这是描述实际动作输入的经验测量，不要求误差为零。

## 图 2：固定图像，力矩改变了哪里

固定图像，分别输入真实力矩、物理空间零力矩、来自其他验证轨迹的完整历史。替换时保持 8 帧历史内部顺序，优先匹配阶段或幅值，避免把历史逐帧打乱引入额外时序因素。物理零值仍经过相同归一化，不把归一化空间的零误认为物理零。

绘制每个 patch 的 `||P_out(I,τ_true)-P_out(I,τ_control)||2`，使用共同色标，同时画原始力矩与动作差异的时间曲线。相同输入重复推理必须得到零差异，作为负对照。不要预先要求最大响应一定落在接触像素：关节力矩与图像位置没有唯一对应。

由于 ACT 同时读取图像和力矩 token，仅替换输入 τ 后动作变化还不能说明变化经过了图像融合分支。应增加一个路径隔离条件：使用控制力矩生成的图像特征，但将 `T_out` 固定为真实力矩前向的结果，再执行相同的 `context_norm` 和 ACT。该条件检查力矩对**图像融合路径**的影响。

热图发生变化仅说明有影响；是否有益仍由下一组配对动作误差判断。

## 图 3：同一 checkpoint 的推理路径干预

不更新权重，对同一验证窗口比较下列条件。每次组合特征后都执行原有 `context_norm`，其他条件保持一致：

| 条件 | 送入归一化的图像特征 | 力矩 token | 检查什么 |
| --- | --- | --- | --- |
| 正常 | `P+U(M-C)` | 原始 `T_out` | 参考预测 |
| 去掉高分辨率细节残差 | `U(M)` | 原始 `T_out` | 动作头是否使用 skip 保留的空间分量 |
| 去掉图像融合更新 | `P` | 原始 `T_out` | 整个图像融合更新是否有益，不能单独归因于力矩 |
| 只干预力矩到图像的路径 | 图 2 控制力矩得到的 `P_out` | 固定原始 `T_out` | 力矩相关图像修正是否有益 |

绘制每条 episode 的配对动作误差、接触附近的时间曲线与误差差值。先按 episode 汇总，再报告总体变化，避免大量重叠窗口制造虚假的独立样本量。只有输出改变而误差没有变差，不足以证明被移除的信息有用。

这些是固定模型的推理干预，不是训练消融；干预可能偏离训练分布，因此需要结合多个条件和图 1 的结构证据解释。

## 可选图 4：模糊强度扫描

对同一图像和力矩使用 `σ=0/1/2.5/5`，比较 DINO 特征相对清晰输入的余弦相似度、图 2 的力矩影响图，以及动作误差。它描述当前 checkpoint 对模糊的敏感性，不能单独证明旧 cross-attention 的训练失败原因。

当前像素模糊发生在 DINO 之前，skip 的 `P` 也来自模糊图像。图 1 的保留结论是相对于本次输入的 `P`，不意味着恢复了模糊前的细节。

## 可以支持的结论

结构分析可以证明特定空间分量被保留；同 checkpoint 的推理干预则检验这些分量以及力矩相关修正是否改善动作预测。若两类证据一致，可以支持“将视觉细节传递与跨模态交互分离”的设计 insight。避免由单幅热图直接宣称“全部信息无损”或“消除了视觉主导”。
