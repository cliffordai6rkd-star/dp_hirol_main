# CIVI：固定 8 样本 Mixed 与 Contact-only 更新方式诊断

2026-11-15；基于 `V / 2443e63e047aff9ba178bc11e0834e5f8205fe60`。本轮仅两组各 20 步，**总计恰好 40 次 optimizer.step，已停止**。没有结构改动、Oracle 重跑、EMA 平滑、完整训练、学习率/RMS 追平或额外缩放试验。

## 结论

**A/B 接近且均改善：本批原混合阶段损失组成不是 Contact 优化的主要阻碍，不继续搜索 Loss 权重。** A/B 的 Contact 预测响应 MSE 从相同的 0.05831591 降到 **0.05272337 / 0.05263240**，下降 **9.590% / 9.746%**；B 仅比 A 低 **0.173%**（绝对差 9.09688e-5）。两组 4 个 Contact 均改善。真实教师响应 MSE 下降 **5.460% / 5.491%**。

实际 RGB 修改量也接近：20 步 Contact 更新 RMS 的 A/B 比为 **0.98830**（A 低 1.17%）；全 8 样本比为 **1.00270**（A 高 0.27%）。逐 Contact 的端点 RMS 差为约 0.41%–3.19%，不是只靠汇总掩盖巨大幅度差。Precontact 更新幅度因 Mixed 真正优化它而有所不同，见逐样本表。没有为匹配幅度改动学习率。

Mixed 同时让 Precontact 预测响应误差下降 **11.750%**；Contact-only 则上升 **2.476%**。因此，删去其他阶段并没有换来明显 Contact 收益，却损失了本批 Precontact 的改善。Free 的初始加权梯度非常小，负余弦不能作为“Free 阻碍 Contact、必须删除 Free”的证据。两组的 Free 实际响应均增大，仍需如实报告其绝对与相对变化，不能称 Free 已被保护。

本轮只支持这一固定批次、初始化和短程更新的结论，不外推全数据，不判断网络容量或全局表达性，也不认定原训练已经充分优化。第一步的有限参数位移出现实际 Contact loss 上升，而 20 步均下降，说明不能用初始原始梯度余弦代替真实 AdamW 更新效果。

## 固定模型、批次和损失

模型起点、Teacher 150,000-step EMA 及其依赖、固定 gates/alpha、原图 epsilon=0.1 约束、FP32 读出均复用 `civi_local_updates_20`。初始模型使用原 checkpoint 的 `ema_model`，之后是**在线模型**更新/比较；不创建 EMA，不加载任何历史 optimizer state。这是新建 AdamW 的局部探针，**不是原训练严格续跑**，也没有将 online optimizer 状态配到 EMA 权重。

Checkpoint：`data/diagnostics/civi_student_iteration/final150k_baseline_s42_3000/best.pt`（step 2800）；SHA256 `fec1fc56443602efc5be1ff84af00afd787f9363f30dcb3e572e64e84e3683d5`；初始 tensor state SHA256 `ec6b32b72646500c89d44d928ea336ab1dbff452f8531ba9db743babf12e61a7`。原六窗口的所有旧 FP32 起点字段与上一轮逐项完全一致。

`E = 冻结 DINO + 投影/嵌入 + 已校准 Adapter + context_norm`；`dS=E(rendered_RGB)-E(original_RGB)`。Contact/Precontact 的每样本损失为全部 784×256 响应元素的 `MSE(dS,dP)`，dP 与上一轮一样由原图 FP32 视觉 token 和冻结匹配 Predictor 预计算一次后固定。Free 的损失为 **MSE(dS,0)**，与原训练一致。真实教师响应误差为 `MSE(dS,dT)`，dT 是 FP32 Teacher 原始扭矩减去归一化前物理零扭矩的响应；它只评估，不进入本轮优化目标。

核对的原训练代码为 `test/run_civi_rgb_iteration.py:330-350`：Contact/Precontact target 为 dP，Free target 为 0；`free_weight=1.0`、`rgb_weight=0.0`。两组准确使用：

```text
LA = (sum(Contact MSE) + sum(Precontact MSE) + 1.0*sum(Free MSE)) / 8
LB = sum(Contact MSE) / 8
```

Contact 每样本系数都为 1/8，只移除其他阶段梯度。B 仍对全部 8 样本执行同形状前向/反向，非 Contact 乘零权重；**每个完整 batch 累积完毕后仅一次 step**。两组都在 0/1/5/10/20 步评估全部 8 样本。关闭数据随机增强与 Dropout。

两组优化器均全新 AdamW：lr=2e-4、betas=(0.9,0.999)、eps=1e-8、weight_decay=1e-4；全局梯度裁剪阈值 1.0。已有可训练 Renderer 参数 1,834,932 个；Teacher、DINO、投影、Adapter、context_norm、Predictor、Condition 及门控不更新。支持区域之外严格保持原图，区域内始终投影到 `original ± 0.1*spatial_gate*alpha` 与 [0,1] 的交集。
