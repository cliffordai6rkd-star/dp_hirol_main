# Attention, context and simulation experiment sources

The paths below are relative to the CIVI repository root. The supplement includes the finished figures in `assets/` and compiles without the experiment archive. The figures use existing recordings and cached model outputs. Episode and anchor indices are zero-based.

The pre-gate weights sum to one over eight keys per patch. RGB comes from episode 0 of `data/board_25hz_3cam_lerobotv3_clean_ma5_l1_12p5`, camera `right_wrist`, anchors 100 and 200. |

Table S13 uses `final.{all,free,precontact,contact}` in the summaries at 5,000 updates. |
